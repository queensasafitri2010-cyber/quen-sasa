### Cara publish ke GitHub Pages (2 menit): 1. Buat akun di http://github.com 2. Buat Repository baru dengan nama `username.github.io` -> ganti `username` dengan username GitHub kamu 3. Upload file `index.html` tadi ke repository itu 4. Masuk ke *Settings > Pages > Branch: main* > Save 5. Tunggu 1 menit, web kamu akan live di `https://username.github.io` Mau aku gantiin nama, warna, dan fotonya langsung jadi versi kamu? Kirim nama lengkap + bidang kamu (contoh: Desainer Grafis), nanti aku generate file finalnya.
